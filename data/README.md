# Course data

Files under `courses/` are extracts of OpenStreetMap data produced by `tools/extract`. They are derivative databases of OSM and are made available under the [Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/).

Data © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright).

Files under `tracks/` are synthetic GPX walks generated from the hole centrelines for Xcode location simulation, plus real recorded rounds where noted. Recorded rounds are the author's own data.

If you fix a course, fix it upstream on openstreetmap.org too, following the [golf course tagging guidelines](https://wiki.openstreetmap.org/wiki/Tag:leisure%3Dgolf_course).
